# 📚 Portfolio Management System

A full-stack **Spring Boot** application designed to securely host and manage documentation, modular content, and media — built with **Java**, **Thymeleaf**, **OCI SDK**, **Docker**, and **GitHub Actions** for CI/CD. This project emphasizes **security, modularity, and modern DevOps practices**, making it an ideal reference for adaptable and production-ready systems.

## 📌 Features Overview

- 🔐 **Security Measures**
  - CSP, XSS protection, header hardening, and input sanitization
- ⚙️ **Automated CI/CD**
  - GitHub Actions auto-deployment to remote server via SSH & Docker Compose
- 🧱 **Modular Design**
  - Thymeleaf fragments and Spring profile-based configuration
- 📘 **Markdown Viewer**
  - Dynamic chapter loading and content rendering
- ☁️ **Cloud Integration**
  - OCI SDK for secure object storage upload/download

## 📥 Getting Started

To clone and run locally:

git clone https://github.com/Chase-developer/portfolio.git  
cd portfolio  
./gradlew bootRun

> For deployment, refer to the [Deployment Wiki](https://github.com/Chase-developer/portfolio/wiki/%F0%9F%90%B3-Dockerized-Deployment-with-DevOps-Practices)
