My Journey

Summary


In January, I made the decision to transition from freelancing to a full-time job. Despite having years of experience, I lacked publicly verifiable credentials, which made job hunting difficult. A pivotal interview at a cybersecurity company inspired me to fully pivot into cybersecurity while also strengthening my full-stack development, cloud, and DevOps skills.

Over the next few months, I systematically tackled my skill gaps by obtaining certifications, working on practical projects, and setting up an end-to-end cloud infrastructure with DevSecOps best practices. I encountered several technical roadblocks along the way, but each challenge refined my problem-solving abilities.

By the end of March, I had successfully implemented a fully automated deployment pipeline, hardened my application security, and gained practical experience in Spring Boot, Docker, Kubernetes, and cloud security. This journey not only reinforced my skills but also prepared me to reapply for the company that had initially inspired me.

Note: This summary is designed for a quick skim, but I highly recommend reviewing the full timeline for a complete picture of my skills and journey. I’m confident that my progress and problem-solving approach will impress you.

March: Practical Implementation & Real-World Challenges

Early March: Cloud & Security Setup

- Set up an Oracle Cloud Free Tier instance for deployment.
- Configured Spring Boot, Docker, and OCI storage securely.
- Ensured sensitive credentials were never exposed by using .env files and secure storage.
- Started implementing DevSecOps best practices.

Key Achievement:

> Successfully integrated Oracle Cloud services while maintaining security.

View Timeline

Mid March: SSL & TLS Configuration

- Purchased a PositiveSSL certificate to secure the application.
- Encountered an issue where Spring Boot refused to detect the correct keystore path.
- Found multiple solutions but ended up using a workaround by mounting the keystore in two locations (/root/.keystore and /app/keystore.p12).
- Successfully implemented HTTPS with TLS encryption.

Key Achievement:

> Overcame SSL-related deployment issues and secured the website with HTTPS.

View Timeline

Late March: Attempting Kubernetes & Automation

- Researched Kubernetes deployment and created:
deployment.yaml, configmaps, secrets, services
- Attempted to launch Kubernetes but hit memory limits (minimum 2GB RAM required, my compute only had 1GB).
- Decided to fallback to Docker Compose due to hardware limitations.

Key Achievement:

> Gained a strong theoretical and practical understanding of Kubernetes.
> Adapted quickly when constraints made Kubernetes unfeasible.

Final March: Implementing Auto-Deployment (CI/CD)

- Set up GitHub Actions for automated deployment.
- Configured GitHub Secrets for Docker and SSH credentials.
- Encountered issues with YAML indentation and Appleboy SSH requiring a new key format—fixed both.
- Achieved automated deployments with GitHub Actions.

Key Achievement:

> Implemented CI/CD automation, reducing manual deployment time to near zero.
> Ensured smooth, secure deployments with minimal downtime.
