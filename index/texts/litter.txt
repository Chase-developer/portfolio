## 2. Incident Summary
A DNS tunneling attack was detected on April 30, 2023. DNS traffic accounted for 20% of total packets while transferring a 40MB file, which is abnormally high. Analysis revealed DNS queries containing hexadecimal-encoded data. The traffic was traced to a known Dnscat2 client. The attacker successfully exfiltrated sensitive PII data.

## 6. Root Cause Analysis
The attacker used Dnscat2 0.07 to establish a covert channel using DNS queries. A lack of DNS traffic monitoring and outbound query restrictions allowed data to be tunneled. Sensitive PII data in a local directory was accessed, repackaged, and exfiltrated over DNS.

---

## 7. Mitigation & Response Actions

- [x] Isolated affected workstation
- [x] Blocked Dnscat2 signatures and tunneling DNS traffic
- [x] Reviewed all DNS logs for lateral movement
- [x] Notified data protection officer due to PII exposure
- [x] Updated IDS/IPS rules to detect DNS tunneling behavior
- [x] Enforced DNS egress filtering via internal resolvers

---

## 8. Recommendations

- Implement strict DNS egress policies (whitelist-based)
- Deploy DNS tunneling detection rules in SIEM/IDS
- Encrypt and monitor access to sensitive files
- Enable endpoint DLP to prevent unauthorized file access
- Conduct employee awareness training on data storage hygiene

---

## 9. Conclusion
A DNS tunneling exfiltration attack led to the unauthorized transmission of 721 PII records using the Dnscat2 tool. The incident was detected via anomalous DNS traffic patterns and has since been contained. No further lateral movement or secondary infections were identified.
